DirtBytes 🧹
A lightweight Python script that helps you free up space by removing unnecessary junk files. Built and refined personally for simplicity and speed.

Installation 🚀
-> Go to the Releases page.
-> Download the latest (or any) .zip file.
-> Extract and run → you’re good to go!

⚠️ Updates may add new features or improvements. Keep an eye on releases! ⚠️

Why even consider DirtBytes?
• Should help clean up unwanted space, and hopefully help your computer run faster..
• Perfect for cleaning up your system before gaming, modding, or development.
• Lightweight and easy to use (as is basically anything python based).
